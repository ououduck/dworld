隐私说明

更新日期：2026-08-16 · 适用于 https://www.pldduck.com

我们收集什么

本站为个人主页，不要求注册、不收集表单内容。仅通过第三方统计服务 Microsoft Clarity 收集匿名的行为数据，用于了解访客如何浏览本站并改进页面：

  • 鼠标移动 / 点击 / 滚动等交互行为（会话录制片段）；
  • 设备类型、浏览器、屏幕分辨率等环境信息；
  • IP 地址（仅用于地域统计，不用于识别个人身份）。

此外，Google Fonts 在加载网页字体时会记录请求方的 IP 地址（仅用于提供字体文件服务）。

数据用途与存储

上述数据仅用于本站的访问统计与体验优化，不会用于广告投放，也不会出售给任何第三方。 数据由 Microsoft 按其 隐私声明 处理。

如何拒绝统计

你可以通过以下任一方式停止被统计：

  • 使用浏览器隐私模式或广告拦截插件阻止 clarity.ms 域名的请求；
  • 在浏览器设置中禁用 JavaScript（将同时影响部分页面动效）；
  • 按照 Microsoft 提供的隐私选项进行设置。
